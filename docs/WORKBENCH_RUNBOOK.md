# 浅色企业首页：运行与交付说明

## 当前实现

首页为 React 18 + TypeScript + Ant Design 5 + ECharts 5 构建的本地工作台，按需求分为顶部、左侧菜单、主体和右侧洞察。数据经真实本机 HTTP 接口加载，默认是明确标记的合成演示；切换真实来源显示未连接与未知值，不静默回退。

实现四项指标、环比与迷你趋势、在线进度环、七日治疗/活跃趋势、事件与历史在线率独立坐标图、用户状态/巡检优先级筛选、用户详情抽屉、全天合成显示样本的缩放/拖动/候选时间线、独立数据丢失率环图（已接收/数据丢失与中心丢失率）。原告警卡的严重快照/模拟开关已移除，告警中心仍保留。数据丢失率只用独立上报计数计算，未知和零分母显示—。设备/用户/告警目录为只读；设置可控制数据源、型号和自动刷新。

右侧为可核对的规则摘要，不是已连接的大模型。报告下载到本机并含数据快照；复核/随访草稿仅保存在本浏览器或下载，不发送通知。页面和抽屉都不把后台用户、合成用户及本地CSV自动绑定。

## 启动

当前文件夹的前端已构建后，可直接双击根目录“启动AI Agent.cmd”，或运行 `python launcher.py`。默认统一入口为 `http://127.0.0.1:8765/`：主工作台和事件检测由同一个服务提供。已有旧服务占用时先关闭旧服务再启动新版；已打开的旧进程不会自动加载新 Python 路由。若明确修改启动端口，所有页面和接口一同使用该端口，不能用研究或预览端口代替主入口集成。

全新源码环境需先构建前端（Node 24、pnpm 10.28.2）：

```powershell
cd page_design/frontend
pnpm install --frozen-lockfile
pnpm test
pnpm build
cd ../..
python launcher.py
```

构建资源输出 `page_design/web/`，无需运行第二个前端开发服务器。开发热更新可在 frontend 运行 `pnpm dev`，API 代理到本机8765。生产源码运行和EXE均使用本地构建资源，不依赖CDN。

`page_design/web/`、依赖和缓存不纳入Git；CI先安装、测试、构建前端，再运行Python/浏览器逻辑回归并打包。根目录 `build_windows.py` 会核对首页资源并包含其完整子目录，以及核心前端依赖许可证。旧 dist/release 程序不随源码自动更新。

## 接口和模块

- `/`、`/dashboard`：新版构建首页；缺少构建时保留旧首页兼容，需完成前端构建才能看到新版。
- `/workbench-assets/`：限定前端构建目录的静态资源，拒绝目录越界。
- `/api/workbench`：型号、来源筛选及概览，只读。
- `/api/workbench/users/{id}`：指定合成用户详情，独立请求，不在首页返回所有长波形。
- `/api/workbench/detection-context`：当前本机记录和全历史标记的只读提示，明确用户归属未验证。
- `/events`：事件检测工作区，默认“动态基线优化测试（v3 · 起点复核）”，去背景绝对值方法、8秒窗口、最短持续10秒；患者流量v4及幅度规则可手动选择，保留波形、扫描、人工复核和导出。
- 首页侧栏“事件检测”使用同源 `/events`，快捷卡已移除；移动端保留侧栏折叠图标入口。检测页页头“← 返回主工作台”返回同源 `/`，侧栏也可返回数据大盘。入口不携带示例用户归属参数，本机CSV不会自动绑定演示用户。
- `/legacy-overview` 与原 `/api/dashboard`：此前用户运营接口和页面兼容入口。

按根目录 `AGENTS.md` 的持久约定：主 agent 只负责需求澄清、方案/接口约定、分派、跨模块协调和验收，可只读审查与运行验收测试，不直接编写业务、页面或算法。页面 agent 负责 `page_design/` 的页面实现、导航、前端构建和页面测试；事件检测 agent 负责 `event_detection/` 的算法、波形、扫描/复核/历史/导出、检测服务及其宿主必要支持。共享服务、打包等实现先明确指定责任 agent，新功能按独立目录与对应 agent 维护。开发协作职责不表示产品内有独立聊天窗口或已运行的大模型调度。保留用户数据、未提交改动与历史检测证据。

## 已明确的范围限制

真实数据库、设备在线状态/延迟、原始波形与用户映射、大模型和外发消息尚未接入。首页及示例用户抽屉中的在线率、优先级、漏气提示、事件与波形均为合成工作流数据；独立事件检测区则读取使用者明确导入的本机CSV，不与这些示例混合。文档提出的10Hz、状态/压力/漏气和暂停规则未被据此加入真实检测算法；演示优先级不是健康评分。

昨日核心指标按演示上海自然日；在线率卡标当前演示快照，其余三卡标昨日。真实后台业务日的跨夜规则仍待验证，后台上报、本地候选与演示模型结果不能相加。时钟不是数据延迟；延迟显示未接入。
