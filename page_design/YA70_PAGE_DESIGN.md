# YA70 巡检页面设计评审

> **建议方案，待用户确认，未实施。** 本轮只产出设计文档和合成演示原型，不修改业务页面、后端、测试或数据库，不连接后台、不导出或下载真实数据。原型不代表已实现的检测或 AI 能力。

## 依据与可信边界

主协调在用户授权下只读观察了 YA70 天统计页面。本设计采用已观察到的字段与入口，不引用真实用户或设备标识。尚未验证后台导出内容、分页完整性、用户归属、分钟数据和原始压缩文件格式。界面有某字段，不等于数据完整、语义已核实或本项目已可读取该字段。

已观察的筛选包括设备 id / picode / userid、单个日期、设备型号、固件、治疗时长下限、治疗压力和排序。型号选项包括 YA70A20、YA70B20、YA70B25、YA70B30/YA70Pro、YA70LAB；合并选项应保留后台原名，不自行认定 B30 与 Pro 可分开统计。

原型新增的“7 天”是未来范围查询的产品建议，不能宣称后台已有范围接口；后台目前只确认单日筛选。跨日完整读取与去重方式未验证，真实接入前不输出全量结论。

## 页面结构：两种评审布局

推荐“巡检优先”：左侧统一应用导航；页顶来源与后台记录日期范围；中间四个已上报统计卡；轻量日期条带；描述性待核查事项与记录列表并列；点击记录在本页展开证据详情。适合先看到日期错位、缺失和待核查字段，再定位记录。

“记录优先”：同样导航与筛选，指标压缩在顶部，紧凑记录表是主内容；日期条带和核查事项放在后面。适合已知目标、日常查表及逐条核对。两种布局使用相同合成数据与计算规则，差异只在信息层级。

主导航建议为巡检总览、记录检索、运营概况和本地检测。原型中前两项可切换；运营概况因注册和实际使用数据未接入而禁用，本地检测因本轮不连接真实文件而禁用并给出说明。实际产品可沿用已存在的单份本地检测入口，但本原型不触发它。

## 字段分组与显示建议

| 分组 | 实际观察字段 | 建议展示 |
| --- | --- | --- |
| 定位与设备 | 用户、设备、picode、型号、固件、硬件 | 表内保留用户字段与型号；设备标识和版本在详情展开。身份映射标“后台字段存在，归属待验证”。原型全部使用示例标识。 |
| 日期与时长 | 后台记录日期、开始/结束时间、治疗时长、创建时间 | 日期列明确命名“后台记录日期”；详情并列显示起止原值和治疗时长上报值，不互相替代；创建时间作为数据来源信息。 |
| 后台结果 | 后台 AHI、暂停次数与持续秒数、中枢次数与持续秒数、低通气次数与持续秒数 | AHI 单独标“后台上报原值，计算口径待核实”；暂停和低通气独立展示；中枢单列，不加到暂停总数，包含关系待核实。 |
| 治疗与信号汇总 | 压力、漏气、呼吸频率、通气等 | 按后台字段原名和明确单位展示；均值、分位数、单位或含义尚不明确时标待核实，不推导新指标。 |
| 证据入口 | APP 图形、分钟数据、压缩文件查看、导出 | 真实接入前只给不可用的示意入口，注明未验证格式、授权及内容完整性。不能假定 APP 图形就是原始波形或压缩包能直接喂给现有算法。 |

空白统一显示“未上报”；它可能代表缺失、未适用或未采集，真实原因待核实，不能补零。类型/单位不明确的值保留原值与状态，不能自动转成有效分析小时。

## 日期、覆盖与汇总口径

1. 主筛选以“后台记录日期”为准，不能悄悄改成开始时间日期或创建日期。已观察到记录日期与起始日期不一致；详情始终并列展示两者。日期差异首先是待核查事项，不自动归类为错误。
2. 后台时区、跨午夜归属、补传规则、记录粒度及重复行规则未核实。原型所用日期为合成示例，不声称后台时区已确定；本项目上海日期约定不能自动套到后台原值。
3. 治疗时长是后台上报值。它与结束减开始可能不一致；不互相填补，也不能视为本地算法有效分析时长。治疗时长原单位、暂停扣除、合并规则均待核实。
4. 首页“有使用记录用户”仅按返回记录中非空后台用户字段去重，标为“当前结果上报字段去重”，不等于全体用户、活跃用户、注册用户或已验证身份。原型只处理合成示例；真实用户映射未接入。
5. “后台治疗时长”“暂停次数”“低通气次数”分别按非空上报值汇总；任一行缺值即标“已上报小计 n/N”，不称全量总计。所有值缺失则为“未上报”；明确上报 0 可以显示 0。重叠记录、重复行和分页完整性未解决时，真实产品的汇总必须带限制或暂停输出。
6. 不汇总后台 AHI，不以 AHI × 时长推算次数，不将暂停、中枢、低通气未经验证地相加；不展示“本地候选/治疗小时”。本地候选密度需要同一方案的有效分析区间与可追溯去重结果，当前未知。
7. 日期条带展示当前型号与日期范围内各日记录数及暂停/低通气已上报小计；没有返回行只写“无示例记录”，不能推断后台没有数据。每天分母与缺失状态同时展示。

## 来源与完整性状态

页顶持续显示“设计原型 · 合成演示 · 未连接后台”；切换布局、视角或展开详情不移除此状态。真实产品建议分开标注：数据源连接、查询范围、分页完整性、字段上报完整性、用户映射、文件可读取性、扫描状态。

- 未连接：不以合成值代替真实结果，真实模式为未知。
- 返回部分页：只能称当前返回记录，不输出全体用户统计；保留后台总数是否已知的状态。
- 有行但字段空：显示未上报与字段上报比例；不能把空值当 0。
- 本地未检测：候选数与密度为“—”，待取得真实文件、算法上下文和有效分析区间；不能拿后台次数填充本地结果。
- 未验证用户归属：允许记录级定位，不产生真实用户排名，不凭 userid 参数直接打开文件。
- 演示无匹配：显示筛选范围内没有示例记录，允许改变型号或日期，不推导真实空态。

## 后台上报与本地候选视角

建议在共同记录范围上提供两个视角：

- 后台上报：显示原始后台 AHI、暂停/低通气和治疗时长；原型值全部合成。
- 本地候选：明确“未检测”，不计算假候选；字段包括检测方案、参数、记录指纹、分析区间和有效时长，当前全部待接入。不与后台 AHI或后台次数合并。

将来做对照时，必须先确认同一记录、相同时间轴、事件定义、重复处理与分母。名称相似不代表可比较，更不能用“后台中枢次数 + 暂停次数”当总暂停量。

## 下钻与分析助手

点示例记录在本页展开详情，保留型号、日期、当前视角和布局选择。详情显示来源记录日期、起止时间原值、治疗时长原值、后台 AHI 原值、事件分项、版本信息和映射状态。明确提示治疗时长与起止跨度不必相等，来源时间未经转换。分钟数据、APP 图形、压缩文件、导出和实际检测入口均禁用并说明条件。

分析助手只是可选的建议问题区域：“哪些记录有未上报字段？”、“后台日期与开始日期为何不同？”、“接入本地检测还缺什么证据？”。原型点击问题只展示明确标记的本地回答示例，不调用模型，不声称完成分析、不自动扫描。未来回答应引用实际记录快照及权限范围，不能越过数据完整性与统计口径限制。

## 可验收评审流程（仅原型范围）

1. 初始显示合成演示状态，YA70 全系列、近 7 天及后台上报视角有可用内容。
2. 切换任一子型号后，四个指标、记录表、日期条带及待核查项取自同一筛选后的数据；无匹配时显示示例空态。
3. 选择单日后，后台记录日期相等的记录纳入，即使开始日期落在次日也不被悄悄排除；切回 7 天恢复对应范围。
4. 上报 0 与空白分开显示；出现缺失的汇总卡显示已上报小计与 n/N，所有缺失不显示 0。
5. 暂停与低通气独立汇总；中枢仅在详情单列，绝不与暂停相加；AHI仅显示逐行原值。
6. 切换本地候选视角后明确未检测，候选指标为未知；返回后台视角可恢复原筛选下的上报汇总。
7. 点击示例行展开正确记录详情，原始日期/时间/时长/AHI并列；文件和执行入口不能触发网络、下载、导出或扫描。
8. 记录检索导航可切换演示内容；未接能力有禁用说明。助手问题仅显示回答示例，关闭助手不会遮住表格。
9. “巡检优先”和“记录优先”由评审轮播切换，分别保留本地筛选状态；1024px 可对比信息层级，320px 控件换行，记录用卡片或局部表格溢出，应用外层无固定高度滚动容器。
10. 原型脚本无外网调用，DOM 标识与选择器匹配；计算由同一小型合成数据集产生，未接入数据的限制始终可见。静态和交互逻辑检查不替代实际浏览器视觉验收。

## 接入前待核实项

- 查询与导出的分页、总数、权限范围、范围查询能力、稳定记录键和重复行规则。
- userid/picode/设备的归属、设备转移或多人使用处理，是否可追溯到具体记录文件。
- 后台记录日期、起止时间、创建时间各自时区及归日、补传/更正机制。
- 治疗时长单位与计算、暂停/中枢包含关系、次数和持续时间的空白/零值含义、后台 AHI 公式与有效分母。
- 压力、漏气、呼吸频率、通气等字段的单位、平均/分位/极值定义和固件差异。
- APP图形、分钟数据、压缩文件格式、采样/时间轴、字段与单位、质量标识、读取权限及完整性。
- 是否满足既有本地算法输入条件，如何获得有效分析区间，跨记录重复暴露如何处理。
- 型号 B30/Pro 的后台合并选项语义及算法、固件间的可比性。

以上仅供用户确认下一步设计；不因原型可点击而认为真实数据链路已接通。
