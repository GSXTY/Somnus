# YA70 后台与本地检测：页面字段映射

**设计建议，待确认，未实施。** 本文依据本轮提供的后台观察描述整理，未独立访问后台、下载文件或验证接口。不得据此宣称数据已接入或用户与原始文件已绑定；不包含真实用户、设备标识。

## 观察边界

**已看到（据提供的观察）：** 天统计行包含下表字段，并有 APP 图形、压缩文件查看、分钟数据入口和导出按钮。型号出现 YA70A20/B20/B25/B30、YA70Pro/LAB。

**待验证：** 导出格式、字段单位与空值编码、按钮实际内容、分页与导出范围、原始文件内容、用户设备历史归属、后台事件算法口径。看到入口不代表可取得完整数据。型号列表仅为已观察值，不代表完整支持清单。

## 字段来源与含义

| 来源/字段（已看到） | 页面建议表达（设计） | 含义待核实 |
| --- | --- | --- |
| 天统计：用户 id、设备 id、picode | 作为后台来源标识分别保留；展示时脱敏 | 各标识含义、唯一性、关联键、换机/共享/历史归属有效期；不能凭当前设备归属倒推历史 |
| 天统计：型号、固件、硬件 | 展示设备上下文，用于追溯与分组 | 型号编码、版本生效时间、不同版本算法与字段是否可比较 |
| 天统计：记录日期 | 原样标“后台记录日期” | 业务日、时区、跨夜归属或结算规则；已观察到日期可能为 11-08 而起止在 11-09，不能自动修正 |
| 天统计：开始、结束 | 单独展示后台起止时间 | 时区、是否多段汇总、端点与中断规则；不据此重建实际治疗区间 |
| 天统计：治疗时长 | 标“后台治疗时长”，保留源单位/精度 | 累计方法、停机扣除、取整、跨日拆分；不要求等于起止差，差异本身不判错误 |
| 天统计：后台 AHI | 标“后台上报 AHI”，原值展示 | 分子、分母、事件定义、时间窗、版本与取整；空白保持未知，0 保持已上报零值 |
| 天统计：暂停次数/持续秒数、中枢暂停次数/持续、低通气次数/持续 | 各项独立标“后台上报”，次数与时长分列 | 暂停是否已包含中枢、分类是否互斥、时长单位及累计方式；包含关系未定，暂停与中枢不能相加 |
| 天统计：压力、漏气、呼吸频率等 | 保留源字段名、单位及统计类型；不明项标待核实 | 均值/峰值/分位值、压力单位、总漏气或非预期漏气、采样及聚合口径 |
| 天统计：创建时间 | 标“后台创建时间”，与发生时间分开 | 入库/上传/计算时刻、时区、补传和重算机制；不作为事件发生日 |
| APP 图形、压缩文件查看入口 | 标“已看到入口，内容待验证” | 是否图像或数据、文件格式、范围、完整性、身份及时间映射 |
| 分钟数据入口/导出按钮 | 标“分钟数据待验证/导入” | 实际粒度、聚合定义、分页与筛选范围、导出是否完整、缺分钟与重复处理 |

**设计：** 来源值、来源字段、单位、空值状态和转换结果应可追溯；空白不能补零。未经验证的分钟级指标不能当原始波形样本或本地有效分析时长。

## 两套事件结果隔离

**设计：** 页面分区展示“后台上报指标”和“本地工程候选与人工复核”，各自携带来源、记录范围、算法/版本及时间口径。后台次数不导入为本地已确认标签；本地候选不回写为后台事件。本地待复核、确认、忽略分别呈现，人工确认仍不是临床诊断。

后台 AHI 仅原值展示，不重算：其事件分类、有效分母及取整规则尚未验证，现有字段不足以可靠复现。本地算法分析机器信号并生成工程候选，未建立与后台事件的一一对应；两者可能重叠且定义不同，不能相加，也不能用本地候选数除以后台治疗时长构造 AHI。后台治疗时长同样不能替代本地按算法、类型及质量条件计算的有效分析时长。

暂不做“差值即误报/漏报”或准确率结论。未来仅在同一记录、可核验时间映射及明确分类关系下提供并列对照；任何匹配门限与判定流程另行确认。

## 天 → 分钟 → 原始记录 → 本地检测

| 层级 | 当前证据状态 | 建议页面状态与下一步（设计） |
| --- | --- | --- |
| 天统计 | 已看到字段及入口；未验证完整导出范围 | “后台天统计”；保留源日期与起止，不宣称代表完整自然日。先核验稳定行标识、修订和筛选/分页范围 |
| 分钟数据 | 仅看到入口/导出按钮 | “入口已观察，数据未验证”；取得并验证后再标“已关联/部分/缺失”，记录所属天行与设备/用户证据。分钟汇总不能自动升级成波形 |
| 原始记录 | 仅看到压缩文件/图形入口，内容未验证 | “原始记录待验证”；验证格式、通道单位、时间轴/采样时钟、内容指纹、覆盖范围及真实归属。文件可打开不等于已绑定该天/用户 |
| 本地检测 | 已有独立单 CSV 检测功能；上述后台链路未接入 | 未绑定时仍标“本地独立记录”。仅映射证据齐全后设计启用“检测此记录”；再区分未扫描、部分扫描、完整扫描但有效不足、待复核与复核完成 |

**设计：** 各层关系允许一对多，不假设一条天统计恰好对应一个分钟文件或原始文件。缺层、冲突、时钟不明或范围不足时明确阻断相应关联结论；不通过 URL 用户参数、文件名或日期相近自动认定匹配。首版不自动下载、批量扫描或写入确认。

页面整合优先确认：标识与历史归属、后台业务日及时间口径、导出完整范围、原始文件可用性，再决定可启用哪些层级入口。其余保留“待验证”，不显示伪造零值或已接入状态。
