# 主窗口弱段残余：只读对照实验

2026-11-09。实现：`event_detection/research/residual_recovery.py`；测试：`tests/test_residual_recovery.py`。原 v3 的实现、默认参数、扫描和标注库均未改变。

## 目的与口径

从既有 `compute()` 的 source、traces、events 出发，寻找连续有效、同 source segment、主窗口 remaining <0.5 的区段。使用 v3 弱段的窗口末端时钟 `[clock,clock+1)`，按记录终点裁剪。NaN、无效秒、非连续时钟和 segment 变化拆断区间。将已有输出全部事件的区间并集从弱段中减去，保留时长 ≥min_duration 的残余片段。

原事件深拷贝保留为 `original_events`；残余独立列在 `review_differences`，标识 `interpretation=review_difference_only`，没有检测事件 id/type/status，不调用存储或扫描接口。证据保留原弱段、剩余比范围、被排除的原事件索引、相交的边界修正拒绝记录。它不能成为自动新增标注入口。

这些片段不代表新增真事件，也不能与原事件数相加。残余可能正是 v3 为排除正常呼气相位、窗口拖尾或短核心而有意删除的部分；主窗口末端坐标也不等同真实波形边界。因此本实验只创建独立待复核差异，不声称更高准确率。若未来修正默认算法，需要先明确事件分段语义并人工验收。

运行示例：

```powershell
python -m event_detection.research.residual_recovery --csv "路径\记录.csv"
python -m unittest discover -s tests -p test_residual_recovery.py -v
```

命令默认向 stdout 输出 JSON；不写事件、不启动服务。回放使用 `Recording` 内存解析、默认 `detrended_abs / W5 / D10`。

## 已完成验证

8 项测试通过，覆盖弱—强—弱真实 compute 复现、强弱交叠并集、边界拒绝证据、质量/NaN/segment 切断、时钟缺口、阈值等号、减去事件后的最短持续、终点裁剪、输入异常和原结果不变性。

合成复现的正常 ±20，弱 ±6，核心 ±0.2；80–96 秒弱、96–108 秒强、108–126 秒弱。原 v3 `absolute_mean / W1 / D10` 仅输出核心 `[96,108]`。实验独立列出 `[81,96]` 和 `[108,127]`；此处偏移一秒来自明确采用窗口末端时钟，而不是偷偷回溯为生理边界。
