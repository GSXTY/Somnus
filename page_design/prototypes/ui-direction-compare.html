首页与项目工具 · 三版设计方向对比

三版原型共用同一组合成数据（昨日活跃 128 人、治疗 342.5 小时、事件 96 次、AHI 4.2，近 7 天趋势），只比较视觉方向与信息层级，不接后台、不读取真实记录。

设计演示 · 未连接后台 · 合成示例数据

方向 A · 轻量清爽卡片风保留现有薄荷绿，补层级与卡片质感

  • 柔和底色 + 两档阴影，卡片有悬浮反馈
  • KPI 卡配图标、趋势胶囊与口径脚注
  • 工具区分组卡片，diff 面板跟随主题
  • 改动集中在 token 与卡片样式，成本最低

取舍：最稳妥、最接近现有品牌；个性偏弱，属于「把现有页面做精致」而不是换风格。

打开方向 A 原型

方向 B · 医疗数据仪表盘风规整分区、报告感，偏运营与医生视图

  • 顶部周期筛选 + 分区清晰的 KPI 条
  • 细边框、克制阴影，表格与图表对齐严谨
  • 指标带环比口径，适合导出日报场景
  • 控件更紧凑，信息密度高于 A

取舍：专业、可信、易读；视觉上偏传统后台，交互活泼感弱一些。

打开方向 B 原型

方向 C · 深色现代工作台深色玻璃质感，偏 Agent 主交互

  • 深墨绿底 + 玻璃面板，强调色高亮关键数字
  • 窄图标轨导航，接近 IDE / 现代工作台观感
  • 深色 diff 面板与等宽代码区一体感强
  • 可复用项目已有 glass 覆盖层方向

取舍：辨识度高、适合长时间工作台使用；深色下图表与长文本需要额外对比度校验。
