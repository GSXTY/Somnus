# Somnus 会话与 Agent 服务

Somnus 是面向项目协作、公司数据查询与深度分析的 AI Agent。会话支持新建、历史、重命名、流式回答和停止生成。聊天使用独立的 `assistant.sqlite3`，与事件标记数据库分离。

## 服务器配置

启动统一 `launcher.py` 前设置环境变量（不要把实际密钥提交版本库或填写到浏览器）：

| 环境变量 | 内容 |
| --- | --- |
| `AI_ASSISTANT_BASE_URL` | 兼容 Chat Completions 的 API 基础地址，例如 `https://your-provider.example/v1`；也接受完整 `/chat/completions` 地址 |
| `AI_ASSISTANT_MODEL` | 服务商支持的模型标识 |
| `AI_ASSISTANT_API_KEY` | 服务器密钥 |
| `AI_ASSISTANT_VISION_ENABLED` | 仅在所选模型支持图片理解时设为 `true`；默认关闭 |

修改环境变量后重启服务。Windows 桌面版也可在配置中心管理自定义模型，模型密钥保存在本机配置中，列表接口只返回配置状态。提供商需要支持流式 `data: ...`，用 `[DONE]` 或已知结束状态结束。流中断时保留已接收的文字并标为未完成。联网采用系统 HTTPS 证书验证。

`configured` 仅表示参数完整；`connection_status=unverified` 表示尚未验证，只有本进程实际完成过回答才标记 `verified` 并设置 `last_success_at`，不保证未来请求可用。启动不自动探测服务。

## 接口

- `GET /api/assistant/status`：当前所选模型的配置与近期验证状态。
- `GET/POST /api/assistant/conversations`：列表/创建，创建可传 `{title}`。
- `GET /api/assistant/conversations/{id}`：会话及历史。
- `POST /api/assistant/conversations/{id}/rename`：`{title}`。
- `POST /api/assistant/conversations/{id}/delete`：`{}`，从列表移除会话，返回 `{deleted:true,conversation_id}`。使用 `deleted_at` 软删除并保留消息原文，不是永久销毁；已移除会话的详情、重命名、发送和取消接口返回404。生成中的会话返回409，请先停止或等生成完成。数据库启动时自动为旧版会话表增补可空字段，不覆盖已有会话。当前未提供回收站或恢复接口。
- `POST /api/assistant/conversations/{id}/messages`：`{content}`，流式SSE `start/delta/done/error/cancelled`；非流式错误 `{error:{code,message}}`。
- `POST /api/assistant/conversations/{id}/cancel`：停止本会话生成。前端先调用再中止fetch。

时间戳为Unix秒。请求体最大15MiB（包含图片base64），问题最多12000字符，响应最多100000字符。同会话并行生成返回409。外部请求连接/读取超时30秒、流总体180秒（阻塞读取可能加一个读取超时）。停止操作立即持久化cancelled并释放会话，旧上游请求至多等待当前读取超时后退出；旧响应不继续写入已取消内容。客户端断开在下一次写入时识别并保留部分回答。重启把遗留streaming标为error，失败/取消整轮不注入后续上下文。

回复可显示模型或外部 Agent 回传的输入和输出 token 数，并随聊天记录保存。内置助手会合计同一轮因工具调用产生的多次模型请求。中断或有请求缺少计数时，已收到的用量标为部分统计。服务未回传用量时显示未返回，既有聊天不补算。

桌面版可为同一个服务商保存多个模型。模型共用服务商接口地址和密钥，模型标识、图片能力及推理强度单独设置。连接测试会发起一次简短模型请求，并提示鉴权、模型、限流或连接类问题。对明确拒绝请求的暂时性 HTTP 错误，内置助手最多在读取响应流前重试一次。已开始读取的响应和已执行的工具不会重放。

### 图片附件

发送格式为 `{content:"问题或空字符串",attachments:[{name:"截图.png",data_url:"data:image/png;base64,..."}]}`。支持纯图提问。仅接受PNG/JPEG/WebP静态图片，单张不超过5MiB、合计10MiB、最多4张；单边最多8192且总像素最多1600万。后端校验实际magic、编码和Pillow图片结构、尺寸，不抓取远程图片URL；图片名称过滤控制字符且最多120字符。根依赖文件已包含Pillow，按项目requirements安装。

`capabilities.vision` 只有模型配置齐备且显式开启图片理解才为true。未开启时发送图片明确报错，不偷偷按纯文本处理。声明开启不代表提供商一定支持；上游拒绝时保留失败状态和原附件供检查。历史消息返回 `attachments:[{name,data_url,mime,size,width,height}]`，列表不包含消息或附件；图片随独立会话库保存，删除会话也保留原文但API不再读取。

上传/粘贴时浏览器本地预览，只有发送时才将附件交给后端并发送到所配置的模型。成功图片问答以标准 `content:[{type:"text",text:...},{type:"image_url",image_url:{url:...}}]` 加入多模态上下文；失败/取消整轮排除。模型上下文的图片总量另限4张/10MiB，超限时按整个旧问答轮次裁剪，避免无界请求。若后续关闭图片能力，含图历史不会静默丢图继续执行，而是明确报错；可开启能力或新建纯文字会话。

## 项目、工具和外部 Agent

- 已配置的公司数据源提供受控只读查询。按本机授权表清单或远程数据网关限制查询范围。看板演示数据、波形记录和检测标记须经用户选择或通过相应工具提供。
- 本轮添加的表格可交给深度分析。任务返回实际任务编号与状态，代码在受控执行环境中运行。项目文件修改建议需在 Somnus 审阅应用。
- 桌面版的内置助手和外部 Agent 都可搜索当前项目授权目录。支持按文件名或 UTF-8 文本搜索，忽略大小写，内容命中附相对路径、行号和片段。内容搜索单文件最多 512 KiB，受整轮搜索范围与结果大小上限约束。
- 已启用的自定义 MCP 可在会话中使用。管理员或本机操作者按服务器实际工具名配置只读权限。其余工具需要在支持修改的会话中逐次确认。工具名与服务器声明不自动授予只读权限。
- Windows 桌面可在配置中心导入 Somnus 插件清单，并在本轮聊天中显式选择已启用的插件。清单引用已安装的 Skill 和 MCP，导入时默认停用。选择插件后，本轮自定义 MCP 限于所选插件引用且已启用的连接，工具权限照常检查。未选择插件时，Skill 和 MCP 仍按各自设置使用。手动选择的 Skill 优先，合计最多 3 个，并受原有指令预算限制。移除插件会保留独立 Skill 和 MCP。
- 「默认」显示内置数据插件及当前 Windows 配置发布的默认插件。只有明确配置所有者权限的本机桌面可发布或移除默认清单。发布后可在聊天中选择，仍需当前配置安装并启用相应 Skill 和 MCP。当前发布只作用于本机应用数据。
- Windows 桌面支持同时运行多条聊天，内置助手和外部 ACP Agent 可以各自在不同聊天中运行。同一个外部 Agent 也可以在不同聊天中独立运行，整个桌面最多同时运行 4 条外部 ACP 聊天。每条聊天同时处理一轮，停止只作用于当前聊天。
- 聊天记录保留原文。发送给内置助手的上下文最多保留最近 6 轮已完成问答，超长问答会标明节选。更早的问答由本机提取文字摘要，优先保留用户约定和关键限制。特别长的聊天会从早期、中间和近期取样。当前问题原样发送，摘要生成无需额外模型请求。
- 每次新建或重建 ACP 适配器会话时，首次请求可附带同一聊天、同一 Agent 的历史文字摘要和近期已完成问答。仍在运行的适配器会话沿用已有上下文。恢复上下文仅使用文字问答，附件和其他 Agent 的历史保持各自范围。
- Windows 桌面可在已授权的项目目录查看 Git 工作区差异。可在项目中保存测试程序和参数，运行前由 Somnus 显示实际命令与目录并逐次确认。外部 ACP Agent 在允许修改的会话中也可请求运行已保存的测试；测试读取磁盘上的当前文件。
- 可以从已授权 Git 项目的当前提交为单条闲置聊天创建工作树。该聊天的项目读取、搜索、文件修改提案、Git 差异和测试均使用工作树，其他聊天继续使用各自的目录。创建前需先处理当条聊天待确认的修改提案。来源移除或项目归档后，绑定停用，工作树文件和聊天记录保留。
- ACP 的任意终端或 Shell 请求仍不获 Somnus 批准。受支持的项目编辑确认仅授权修改临时副本，原始文件仍需在 Somnus 审阅并应用修改提案。对修改后的文件运行测试前，请先应用提案。外部 Agent 的本机程序权限由其自身运行方式决定。
- ACP 每轮最多调用 16 次 Somnus 提供的 MCP 工具，需确认的调用也计入。临时副本编辑确认每轮最多受理 12 项。两类确认共用队列，同一时间最多有 4 项待处理（含正在显示的一项），每次只显示一项。


这是本机单操作者版本，没有登录、租户隔离或服务器多人权限。对外部署前需要统一鉴权、会话归属和数据访问控制。

Somnus 插件使用下列 JSON 清单格式。导入时将示例 ID 换成配置中心 Skill 和 MCP 列表中已安装条目的 ID。清单可只引用其中一类，至少需要一个有效引用。该格式只接受配置引用，用于 Somnus 的插件库。

```json
{
  "name": "文档审阅",
  "description": "使用已安装的审阅技能和文档工具",
  "version": "1.0.0",
  "skill_ids": ["0123456789abcdef0123456789abcdef"],
  "mcp_ids": ["document_tools"]
}
```

本机所有者可在受控启动环境或当前加载的本机 `.env` 中设置 `VV_MAN_PLUGIN_DEFAULTS_OWNER=1`，重启桌面后生效。Windows 打包版先查找后端程序旁的 `.env`，然后使用 `%LOCALAPPDATA%\VVFLY\RespiratoryViewer\.env`，如配置了 `AI_AGENT_DATA_DIR` 则使用其目录下的 `.env`。默认关闭，仅应用于具备本机桌面授权的请求。

验证：`python -m unittest tests.test_ai_assistant -v`（模拟本机上游，不依赖真实模型密钥）。

## FastAPI 宿主

`ai_assistant.asgi.create_router()` 提供原有 `/api/assistant/*` 的原生 ASGI 路由。宿主设置 `app.state.assistant_service`，或提供同步 `assistant_service_for_request(request)` 返回对应浏览器会话的独立服务。服务器隔离模式不得回退到旧共享库；本机共享模式可保留原历史。浏览器隔离标识不是账号认证，公网部署仍需统一身份与访问控制。

模型读取与SQLite操作在线程执行，SSE客户端断开后清理生成器并释放会话。上游阻塞读取仍受已有30秒超时约束。请求体按实际流读取限制15MiB，图片校验及上游配置保持原规则。服务器统一负责POST同源检查。

测试：`python -m unittest discover -s tests -p test_assistant_asgi.py -v`。
