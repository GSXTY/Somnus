# FastAPI 数据分析适配

`install_routes(app, data_dir, initial_file=None, session_mode='isolated')`
注册现有 `/api/open`、波形、扫描、标记、批次、反馈等接口。它在进程内调用既有
检测处理器，不启动旧 HTTP 端口，也不通过网络代理旧服务。算法、历史存储与默认
v3/8秒/10秒保持不变。

## 两种上下文模式

- `isolated`：ASGI 工厂默认。浏览器使用服务器生成的 HttpOnly、SameSite=Lax
  cookie 保存不透明上下文标识；HTTPS 时加 Secure。各上下文的当前文件和缓存独立。
  未知或过期标识不会通过 file_id 接管另一上下文。相同文件指纹的持久标记和扫描
  仍使用原共享事件库，因此这不是账号或租户权限系统。
- `shared`：仅供回环地址的本机协作。浏览器与原有不带 cookie 的 MCP 桥共用一个
  当前文件。所有客户端看的是同一上下文；不得用于多人服务器部署。共享模式不
  因空闲超时清除当前文件。宿主负责拒绝非回环地址启用此模式。

现有 `respiratory_mcp.py` 保留本机 127.0.0.1 HTTP 限制。它在本机 shared 模式中
保持兼容；isolated 模式没有浏览器会话配对机制，不能发现浏览器当前文件。不要
通过关闭服务器隔离或暴露 cookie 作为远程多用户 MCP 集成方案。

## 当前迁移边界

适配器使用全进程锁在单个调用期间绑定并恢复旧检测模块全局状态；扫描/波形
请求在工作线程中串行执行，聊天 ASGI 流式路由不持此锁。**只支持一个 Uvicorn
worker**。不要同时在同一 Python 进程使用直接操作旧全局状态的 MCP/旧宿主。
未来要并行计算或多个 worker，需要把记录/任务状态迁至显式服务或共享持久层。

默认最多16个隔离上下文、空闲1小时过期、单次CSV上传128MiB、全部上下文波形
数据预算512MiB。过期会清除内存文件和缓存，不清除数据库记录；原CSV须重新选择。
上下文满时返回503，超大上传413，内存预算不足507。内存预算包括当前记录及解析
缓存估算，不是操作系统进程RSS限制。单个请求的解析可产生临时内存，部署应同时
配置反向代理请求体和进程资源限制。文件名不用于任意磁盘路径读取。

### 调整文件和内存限额

在启动服务前配置下列环境变量；重启后生效，健康接口返回实际使用的
`runtime.detection_limits`。数值必须为正整数，配置无效时启动失败，不静默回退。

| 环境变量 | 默认 | 允许范围 |
| --- | --- | --- |
| `AI_AGENT_MAX_UPLOAD_MB` | 128 | 1–1024 MiB |
| `AI_AGENT_MAX_MEMORY_MB` | 512 | 1–65536 MiB |
| `AI_AGENT_MAX_SESSIONS` | 16 | 1–256 |
| `AI_AGENT_SESSION_TTL_SECONDS` | 3600 | 1–604800 秒 |

旧本机查看器允许最大1GiB CSV。若整夜文件较大，可将
`AI_AGENT_MAX_UPLOAD_MB=1024`，同时按机器可用内存提高
`AI_AGENT_MAX_MEMORY_MB`（例如8192）。CSV解析后的数组可能远大于原文件，
提高上传限额不保证内存预算足够；应以实际数据测试后配置。缓存和历史库不会
因为改变这些参数而被删除。

`/api/feedback/open-folder` 在服务器适配模式明确禁用，避免远程请求在宿主电脑
打开窗口；原有反馈导出仍由服务端生成在既有数据目录中。部署账号鉴权、数据库
映射和导出访问权限由主服务器统一接入，本模块不宣称已经完成这些能力。
