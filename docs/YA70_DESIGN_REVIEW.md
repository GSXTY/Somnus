# YA70 页面设计评审：基于已观察后台字段

状态：设计原型，待确认，未接入后台、未修改生产页面。观察日期：2026-11-09。

## 已确认与未确认

本次依据是在用户电脑 Edge 中只读看到的 YA70 天统计页，不是数据库接口验证。已看到日期/用户/设备/型号/固件等筛选、导出按钮、分钟数据入口，以及每行 APP 图形和压缩文件的查看入口。

型号选项为 YA70A20、YA70B20、YA70B25、YA70B30/YA70Pro、YA70LAB。它们仅是已看到的页面选项；正式接入仍应建立后台型号值与产品系列映射。默认全系列时必须显示包含范围，LAB 单独可筛，不能默默将实验设备与其他设备当成同质群体比较。

尚未确认：导出字段/格式、按钮导出当前页还是所有筛选结果、分页总量、日期筛选语义、数据更新延迟、后台指标单位/定义、事件包含关系、原始压缩文件内容、用户设备归属历史和接口。原型的 7 日范围是新工作台的设计，不代表后台已支持原生多日导出。

## 推荐页面布局

推荐“巡检优先”：左侧功能导航；顶部固定 YA70 来源与日期口径；上方少量摘要，中部每日变化，下方需排查记录，右侧按需展开分析助手或详情。另提供“记录优先”布局供评审，强调筛选与明细表，适合研发逐条复核。

本轮原型只使用虚构示例标识和合成数据。型号及日期选择应重新计算摘要、趋势与明细，点击一条示例记录展开该条详情。查看导出、分钟、压缩文件与本地检测时明确尚未接入，不发送请求、读取真实文件或运行检测。

### 首屏摘要

- 有使用记录的用户：按所纳入记录的用户标识去重，不称累计注册用户。
- 后台治疗总时长：使用源字段，不由开始结束时间推算；正式合计前核实唯一记录、单位与重复情况。
- 后台暂停次数、后台低通气次数：分别展示；源字段缺失时标示已上报小计和缺失条数，不补零。

AHI 等由后台上报的指数放在记录详情，保留来源与原值，不进行无依据的跨记录平均，也不与本地候选密度互换。中枢次数独立展示，包含关系核实前不追加到暂停总数。

### 筛选与日期

第一层为后台记录日期范围、YA70 子型号与数据来源；设备/用户/固件等高级条件置于展开区，避免首屏堆满后台所有字段。预设范围建议近 7 日和选定一天，对照期在完整性和同口径满足后再启用。

默认按“后台记录日期”归组并明确标签。已观察到记录日期和开始时间可能跨日，不能直接替换为开始日期，更不能擅自平移一天。详情同时展示记录日期、开始结束、创建时间和后台治疗时长，提醒它们是不同字段。时区与后台业务日规则确认后才提供另行定义的自然日视图。

### 记录列表与详情

主表精简为用户、设备/型号、后台记录日期、治疗时长、暂停/低通气、来源和查看详情。详情分为身份与记录、使用与原始指标、后台事件、数据质量/缺失、后续证据入口。固件、漏气、压力、频率和通气量等放详情，原始单位未知时标记待确认。

单行粒度、唯一 ID 未确认时不能把 userid + 日期直接当唯一记录键。同一用户可能有多个设备或同日多段记录；需要源记录 ID 或明确去重依据。数据清单不完整时注明已取得范围，不做全体用户结论。

## 两条结果链应隔离

后台上报：天统计 → 分钟数据 → 压缩/原始文件入口，现阶段仅验证了入口存在。上报结果不因本地复核被改写。

本地候选：选定可读取、格式验证通过的原始记录 → 指定方案/参数扫描 → 候选 → 人工复核。未经扫描显示未检测；没有可靠有效分析区间时不显示候选密度。后台治疗时长不替代本地有效分析时长。

二者未来可按已验证的记录映射并排核查，不能相加成“事件总数”，不能根据后台缺失字段自动启动本地补扫。

## 与子 Agent 的交付分工

- 页面 agent：page_design/YA70_PAGE_DESIGN.md 与对话内 YA70 双布局交互设计预览。
- 检测 agent：event_detection/YA70_SOURCE_MAPPING.md，明确字段来源及证据衔接缺口。
- 主 agent：本文件、字段与状态一致性审阅、合成指标与筛选行为检查；不更改现有 dashboard 或算法。

## 评审重点

1. 首页是巡检优先还是记录优先。
2. 型号默认全 YA70 系列还是指定生产子型号；LAB 始终可见且不被默默排除。
3. 首页四项摘要是否有助排查；注册增长暂不从本页推算。
4. 按后台记录日期展示是否符合内部使用习惯，业务日规则需向数据负责人核实。
5. 首轮接入可先验证一日导出，再扩展多日完整数据与原始文件关联，不能直接承诺自动全量同步。

## 新增视觉方向：深色科技蓝数据大屏

> 此方向现保留为历史参考。用户随后明确要求“有高级感、成熟的企业用”“TechUI 也可以参考”“浅色风格”；当前推荐以文末浅色企业方案为准。

用户提供的参考图采用深蓝底、顶部居中标题、渐变摘要、青蓝图表和紧凑面板网格。新增同类视觉评审版本，不自动替换业务首页或已保留的浅色图表方案。

建议将大屏风格用于巡检总览：减少宽侧栏、增加图表画布，保留图表点击和记录下钻；日常明细仍可切换到记录视图。装饰不遮挡数据，不增加假实时闪烁、风险评分或未经验证的告警等级。固定暗色符合本次参考，但手机和较小窗口应重排，不整体缩小文字。

如果用环形图，建议只表示已取得记录内“某字段已上报/未上报”的互斥比例，标明字段和记录分母。它不是全量数据覆盖率，更不能作为健康或算法准确率评分。空结果和未知值仍按未知处理。
