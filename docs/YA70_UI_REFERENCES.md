## 推荐改版：少量摘要 + 三类可下钻图形

1. **每日变化主图。** 暂停和低通气上报量分别显示，附对应日期的记录数、缺失数；治疗小时作为独立对齐视图，不与事件数量共用含混的双轴。
2. **用户×日期矩阵。** 暂停或低通气选择其中一项着色，快速发现变化集中日期与示例用户；色深表示数量，不是临床风险。点击单元格聚焦记录。
3. **后台治疗时长分布。** 按每份记录的后台治疗分钟换算分箱，观察记录主要集中在哪个时长范围。它不是用户日使用分布；缺失不进入零时长箱。

最多保留 2–3 个紧凑摘要，让图形占首屏主体；记录表作为证据下钻，精确数值仍可按需展开。助手围绕当前筛选解释来源与缺口，不自动把“最多”写成“异常”。

## 本轮保留的统计边界

- 只使用 YA70 已观察字段和独立合成记录，不访问真实后台、导出文件或训练模型。
- 按后台记录日期归组，不把开始日期替换进去。前端范围是产品设计，不代表后台已经有完整范围接口。
- 暂停、低通气分别呈现；中枢与暂停的包含关系未确定，不追加成总数。AHI 仅在记录详情标源值，不做跨记录简单平均。
- 0、未上报、有记录但所选字段全缺失、无记录分别处理。部分上报只标已上报小计，不能当完整总体。
- 汇总与图形来自同一筛选集合；用于重选的导航图可保留完整周，但必须显式区分全周导航与当前聚焦。
- 图形可交互不等于生产接入：原始文件、真实用户归属、导出完整性和算法有效时长仍待验证。

## 当前不建议加的图

- 事件类型饼图：类别是否互斥未确认，不能制造组成比例。
- 风险仪表盘与红黄绿阈值：尚无经过确认的内部触发标准。
- AHI 总体均值或与本地候选率叠图：分母和算法语义不同。
- 型号/固件“优劣排名”：未经同类人群、暴露时长和算法可比性控制，容易误读。

## 原型评审要点

主要看图形能否帮助“找到日期 → 找到用户/记录 → 查看证据”。验证切换型号、选择日期/热力格、选择分箱和清除聚焦时摘要与明细一致；无匹配与缺失不伪装成 0；窄屏坐标单位清晰。旧版巡检原型保留，图表版独立评审，未经确认不替换业务首页。
