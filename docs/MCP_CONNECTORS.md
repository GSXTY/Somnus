# Windows 桌面端 MCP 连接

在「模块中心」点击「添加 MCP 服务器」，保存后再点「测试」。测试会连接服务器并读取工具列表。启用后，AI 助手可在后续回复中调用这些工具。停用或删除会关闭连接，从后续会话中移除工具。

- **STDIO** 启动本机可执行文件，参数逐项填写。服务器在 stdout 输出换行分隔的 JSON-RPC，日志写入 stderr。Windows 上可用 `python.exe`、`node.exe` 等程序，npm/npx 可用 `node.exe` 加对应 JS 入口。命令使用当前 Windows 用户的权限。应用传入基础系统环境变量和在连接中填写的环境变量。
- **HTTPS Streamable HTTP** 填写 MCP 服务端点。支持 2025-11-25 握手及服务器协商的 2025-06-18、2025-03-26；2026-07-28 连接需显式选择对应协议。可配置固定认证请求头。HTTPS 连接验证系统信任的证书，拒绝跳转。支持工具列举和调用，暂未接入交互式 OAuth、旧式 HTTP+SSE 或服务器要求的采样和交互输入。

默认配置保存在 `%LOCALAPPDATA%\VVFLY\RespiratoryViewer\mcp.json`，也会随 `AI_AGENT_DATA_DIR` 或 `--data-dir` 使用实际数据目录。设置 `MCP_CONFIG` 时优先使用该文件。没有用户配置时，可读取项目目录的旧配置，首次保存写到用户数据目录。重启后保留启用状态，连接按需建立。环境变量和认证请求头的值保存在本机配置文件中，页面仅显示键名。请限制本机文件访问权限，连接配置不要随安装包或日志分享。

连接设置仅对本机桌面开放。局域网数据网关不会管理或启动本机 MCP 进程。
